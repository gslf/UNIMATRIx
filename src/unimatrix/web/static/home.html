Help

About UNIMATRIx · Polis

UNIMATRIx benchmarks a local language model as the steward of one simulated society. The model reads a weekly briefing and decides what to do; residents live their week, and neglect compounds.

How scoring works

  • Unbounded points. Each domain counts something real (trust-weeks, coins created, fish harvested, skills kept alive…). Exchange rates turn those units into points; nothing caps the total.
  • Collapse scores zero. Famine, a dead lake, a revolt, a lost vote of confidence or a scattered village ends the run and forfeits everything earned.
  • References are milestones, not caps. Scripted stewards play the same seeds; "1.3× expert" places a model relative to them, and strong play can go beyond the oracle.
  • Seeds. A recipe with several seeds averages them; each collapsed seed counts as zero.

Reference stewards

Passive
Takes no action at all. A well-designed society collapses under it.
Random
Acts at random. Used to check that the society cannot be survived by luck.
Naive
Answers explicit requests and follows explicit advice, like a weak but attentive model.
Expert
Reads only the briefing a candidate gets and follows sound heuristics.
Oracle
The expert with access to the hidden state. Optimistic, never a cap.

How long a run takes

One model call per simulated week, about 2.5k prompt tokens (a static half is cacheable). Standard v2 makes 52 calls: about 13 minutes for a 27B model at roughly 15 seconds per answer on a single RTX 5090. Hell v1 plays three seeds, 156 calls (about 39 minutes); parallel seeds run them side by side if your server can answer several requests at once.

Runs survive interruptions: the decision log is replayed through the deterministic engine when you resume.
